# Voice calibration

Use this file to improve the profile over time.

## Strong positive examples

For each example record:

- context;
- text or excerpt;
- why it feels authentic;
- which profile rules it confirms.

## Strong negative examples

For each example record:

- context;
- text or excerpt;
- what feels wrong;
- which rule should be added or corrected.

## Feedback log

Track concise corrections such as:

- too formal;
- too polished;
- too many headings;
- wrong vocabulary;
- not enough uncertainty;
- too much uncertainty;
- too generic;
- invented emotion;
- wrong reasoning shape.

## Profile revisions

Record significant changes to the voice profile and why they were made.
