# Scoring and confidence

The model is a decision aid, not a rigid formula.

## Keep three dimensions separate

For each candidate, distinguish:

1. **Concept fit** - how well the premise/design matches the supplied profile.
2. **Execution confidence** - how strong the evidence is that the work actually delivers those traits.
3. **Medium/path fit** - how suitable this version, adaptation, platform, edition, or release state is for the user.

A new work with an ideal premise can have high concept fit and low execution confidence.

## Use profile-relative weights

Do not ship a universal list of fixed preference weights. Read them from the
user profile.

A profile may define dimensions such as:

- mystery/discovery;
- emotional payoff;
- atmosphere;
- worldbuilding;
- authored identity;
- forward momentum;
- complexity;
- systems/agency;
- level design;
- mastery/flow;
- tactics/strategy;
- simulation/economy;
- friction sensitivity.

Use weights comparatively. They are heuristics, not psychometric measurements.

## Modifiers

Profile-specific bonuses or penalties are acceptable when supported by
calibration evidence.

Examples of modifier categories:

- special subject/theme affinity;
- static/repetitive structure;
- style without substance;
- generic/committee-made feel;
- high friction before investment;
- particular presentation/medium constraints.

Explain material modifiers rather than silently applying them.

## Confidence

Confidence should reflect evidence quality, not enthusiasm.

Useful evidence levels:

- **high** - completed work, repeated calibration, strong consensus on the relevant trait;
- **medium** - meaningful evidence but some uncertainty;
- **low** - premise/trailer/early-release evidence, limited sampling, or conflicting reports.

## Journey vs payoff

When relevant, report both:

- journey / moment-to-moment fit;
- retrospective / payoff fit.

This prevents a giant ending from hiding a poor journey, or a slow journey from
hiding an unusually strong payoff.

## Rankings

Do not blindly sort a scalar score.

For a practical ranked list, consider:

- personal fit;
- execution confidence;
- commitment/friction;
- current availability;
- variety;
- what the user has already consumed;
- low-friction tests;
- timing/version state.

For weak evidence, prefer score ranges or qualitative bands over false decimal precision.
